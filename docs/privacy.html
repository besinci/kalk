Privacy policy

Last updated: October 17, 2026

Kalk collects no personal data. No account, no analytics, no ads. Your settings and break log never leave your computer.

What is stored on your computer

  • Settings (interval, reps, active hours, language and so on) in settings.json.
  • Break log in kalk.db: the time of each reminder, its outcome (done, skipped, snoozed or missed) and the number of reps. Stats and your streak are calculated from it.

Both live in Kalk's app data folder. Uninstalling the Microsoft Store version removes them too. We don't share these files with anyone, because we never have access to them.

Keyboard and mouse

To count only the time you're actually at the computer, Kalk asks the operating system how long ago the last input happened. It never reads or records what you type, where you click or what is on your screen.

Network access

The Microsoft Store version makes no network connections at all; the Store handles updates.

The version downloaded from GitHub fetches a small file (latest.json) from GitHub Releases every few hours to see whether a new version is out. The request sends no data about you; what GitHub sees with any web request (such as your IP address) is covered by GitHub's privacy statement.

Children

Kalk collects no data from anyone, children included.

Changes

If this policy changes, the new version is published on this page with a new date. Kalk is open source, so you can check what it does yourself on GitHub.

Contact
